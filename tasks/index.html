Tasks and Schedule¶

Upload your project schedule to compare what was planned with what happened on site. Once each task is linked to the zones where the work happens and the roles that do it, SMART can show planned hours against recorded hours, by zone and by role.

Select Tasks in the navigation panel to open the schedule as a Gantt chart.

Uploading a schedule¶

SMART reads Primavera P6 (.xer) and Microsoft Project (.mpp, .pp) files.

  1. Open Tasks. If no schedule has been uploaded yet, select Open Schedule Loader. Otherwise select Upload schedule.

  2. Drag the file onto the loader, or select it from your computer. The loader shows when the last schedule was uploaded.

  3. When the upload finishes, SMART asks you to match the new schedule to your zones and roles (see the next two sections).

Upload each new version of the schedule as it is issued, so SMART always compares site activity with the current plan.

Screenshot

The schedule loader

Matching activity codes to zones¶

If your schedule uses the SMART Breakdown Structure activity code, SMART Breakdown Structure - Activity Code Assignment opens after the upload. Choose the workzone for each code. Every task with that code is then linked to that zone.

The window has three lists:

  • New Smart Breakdown Zones: codes that are new in this version. You must assign these before you can continue.

  • Matching Codes: codes carried over from the last version, with their zones.

  • Removed Codes: codes that are no longer in the schedule.

If you linked tasks to zones by hand in the last version, tick the ones to carry forward under User-added zone assignments. Select Save & Continue.

Matching schedule resources to roles¶

Sync P6 Resources with SMART Roles lists each resource in the schedule, with its tasks and budgeted hours. Choose the matching SMART role for each, then select Save. The roles then show on the tasks in the Gantt, and their hours count as scheduled hours in Analytics.

To change these matches later, select Manage Smart Role Assignments above the Gantt.

Reading the Gantt chart¶

Screenshot

The Gantt chart in SMART

The task list is on the left and the timeline on the right. Select Gantt legend to see the colours for WBS rows, schedule bars, baseline bars and milestones, and which data date you are comparing against.

  • Move around: drag the timeline, and scroll to move up and down the tasks.

  • Zoom: use Zoom in, Zoom out and Fit to width, or Reset chart view to start again.

  • Group rows: Collapse all and Expand all open and close the WBS levels.

  • Task details: select a task’s name to see its Details, Resourcing, Activity Codes and User-Defined Fields.

  • See where a task happens: double-click a task to highlight its zones on the map. Select a zone name on a task to fly to it.

To see a different version, select Choose different schedule version and pick one by its data date. Select Download Gantt to XER file to save the schedule, with its SMART links, as a P6 file.

Filters and highlights¶

Select Filters to show only some tasks. You can combine:

Filter

Shows

Active

Tasks underway in the period on the timeline

Zero Float

Unfinished tasks with no float

Driving Path

Tasks on the driving path

Has Baseline / No Baseline

Tasks with or without baseline dates

Has Resourcing

Tasks with planned hours

No Location Assigned

Tasks not linked to any zone

You can also filter by Role hierarchy and Zone hierarchy. Clear filters removes them all. If the map is filtered to some zones, the Gantt shows only the tasks in those zones, which gives you a short Gantt for one area.

Highlight Tasks colours tasks that are Active, on Zero Float or on the Driving Path without hiding the others, and highlights their zones on the map. Use it to see where work should be happening right now.

Assigning tasks to zones¶

Tasks are usually linked to zones through activity codes when you upload the schedule. You can also link tasks by hand:

  • One task: drag the task’s name from the Gantt onto a workzone on the map. If several zones overlap where you drop it, choose which ones to link.

  • Many tasks: drag a WBS or parent row onto a zone. In Bulk Task to Zone Assignment, tick the tasks to link and select Assign. Existing links are kept.

To remove a link, select the cross beside the zone name on the task.

Links belong to the schedule version they were made in. When you upload a new version, use Import assignments from previous version to copy them across. Tasks are matched by task code, and you can choose to skip or overwrite tasks that already have links.

What areas should I assign to a task?

Assign every area where a lot of time will be spent on the task. If crews will spend a long time loading at a stockpile, for example, assign the stockpile too. SMART can then show where the time went, by zone type.

Dragging a task onto a workzone

Assigning resources to tasks¶

Resources come from the schedule when you match its resources to roles. You can also add roles to a task in SMART:

  1. Select the task in the Gantt.

  2. Select Toggle Resources and Crews panel above the Gantt. A banner shows which task you are assigning to.

  3. In Resources & Crews, add each role you need and set the quantity, or select a crew to add all of its roles. See Crews.

  4. Select Done.

To review or change what is on a task, select the resources cell on its row. Use Manage Resource Assignments in the task’s right-click menu to edit or delete role requirements.
