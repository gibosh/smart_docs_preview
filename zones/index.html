Zones and StructuresUpdated 24 Nov 2026

Zones and Structures¶

Zones are areas you draw on the map. Workzones show where work happens, so SMART can measure time spent in each area and compare it with the schedule. Exclusion zones mark places people should stay out of and raise an alert when someone enters. Alert zones decide who is contacted when someone raises an SOS inside them. One zone can be all three at once, so you only draw each place once.

This page also covers 3D structures, such as buildings and tanks, and the Bluetooth beacons that locate people indoors.

Workzones¶

Select Zones in the navigation panel to open the zone tables. The Work zones, Exclusion zones and Alert Zones tables sit side by side, with a search box above them. Selecting zones on the map limits the tables to those zones; select Clear in the banner to show them all again.

Tip

Draw zones for stockpiles, laydowns and access points as well as work areas. The more of the site you map, the more SMART can tell you about how people and plant move around it.

Screenshot

The Zones screen with the Work zones, Exclusion zones and Alert Zones tables

Creating Workzones¶

  1. Select Map Tools, then Create Zone. Click and drag for a rectangle, or use the polygon button and click to place each corner.

  2. When you finish the shape, choose Work Zone in the pop-up. (The same pop-up offers Exclusion Zone and Alert Zone.)

  3. In Create New Work Zone, enter a Name and choose a Type. Optionally choose a Parent Zone and add up to three links, for example to drawings or permits.

  4. Select Create.

Screenshot

The Create New Work Zone window

Editing Workzones¶

Select the zone in the Work zones table and select Edit Zone, or use Edit details in the row’s menu. You can also select the zone on the map and choose Edit work zone in its pop-up.

In Edit Workzone you can change the name, add a Short Label, change the parent and type, update the links and set Time Phasing. Turn on Ignore from recording for places such as crib rooms and site offices, where time spent shouldn’t count towards recorded hours in Analytics. Changes to a zone’s name or shape show in every table where that zone appears.

To change the shape, select Map Tools, then Edit Zone, then the zone. Drag a corner to move it, drag an edge to add a corner, and right-click a corner to remove it. A zone needs at least three sides. Select Save when you are done.

To delete a zone, select it and select Delete Zone. If the zone is also an exclusion or alert zone, all of its uses are deleted together.

Uploading Workzones¶

If your zones already exist in a drawing or GIS file, you can upload them instead of drawing them.

  1. Select Upload above the zone tables, then Upload work zones.

  2. Choose a file up to 10 MB: GeoJSON (.geojson), a zipped shapefile (.zip with matching .shp, .dbf and .prj files), or CAD (.dwg, .dxf). Only closed shapes can become zones.

  3. If SMART asks, choose the file’s coordinate system, such as GDA2020 / MGA zone 55 or WGS84 (GPS Coordinates).

  4. Select the areas to import. Choose which file attributes to use for each zone’s name, information, type and links, or use Set for all to give every zone the same value. You can also choose one Parent zone for them all.

  5. Select Create.

The uploader is in beta. CAD files import best when converted to GeoJSON first. If a file won’t import, contact support@lware.com.

Screenshot

Selecting which areas to import from a file

Activity Assignment¶

Workzones link to your schedule through activity and resource-assignment codes. After you upload a schedule, check the SMART Breakdown Structure and choose the workzone for each code. Tasks with those codes are then linked to that zone, and the Work zones table shows each zone’s Assigned task count and Scheduled hours. See Tasks and Schedule.

Linking a parent zone doesn’t link its children. A zone that is linked to a schedule must keep a work type until its links are removed.

Workzone Types¶

Zone types group zones for the map, the tables and Analytics. To manage them, open the Main Menu, select Device Management under Project, then the Zone Types tab.

Work, exclusion and alert types each have their own list. To add a type, enter its name, choose a Parent type if it is a more specific kind of an existing type, and select Add. You can rename types, change their parent within the same list, set the Colour of work types and choose whether each type is counted in Analytics (Include in analytics). A zone is counted if any of its types is included. Each type has its own setting, so excluding a parent type doesn’t exclude its children.

Types are separate from parent zones: a type says what kind of area a zone is, and a parent zone says which larger area it sits in.

Note

For areas people must stay out of, such as heritage sites, give the zone an exclusion type and set up alert rules for it. A work type on its own doesn’t raise alerts.

Time-Phased Workzones¶

Some areas only exist for part of the project. Set Time Phasing in Edit Workzone to control when a zone shows on the map:

Option

The zone shows

None

Always

Manual

Between the Start and End dates you set

Activities

From the start of its first linked task to the finish of its last

Nested Workzones¶

Use parent zones to organise the site into areas and sub-areas, for example a precinct, the buildings in it and the work areas in each building. Work, exclusion and alert zones can all have a parent, and the parent can be a different kind of zone.

Choose the parent when you create or edit the zone. Drawing one zone inside another doesn’t link them, and choosing a parent doesn’t change either shape or copy any alert rules.

In the Work zones table, select the arrow beside a zone to show its children. Select Group by type above the table to group zones by type instead, and Return to ungrouped to go back.

Screenshot

Nested workzones in the Work zones table

Time in Zones¶

The Time in zones figures measure how long resources spent inside each zone. Where zones overlap, each zone gets the full time: ten minutes inside two overlapping zones counts as ten minutes for each, while the resource’s own total stays at ten minutes. Gaps in tracking data show as unavailable, not as time outside the zone.

Schedule comparisons use a different calculation that gives time to the smallest zone a resource is in, so their figures can differ from Time in zones.

Exclusion Zones¶

Exclusion zones mark high-risk, heritage or environmentally sensitive areas. When a tracked resource enters one while an alert rule is active, SMART raises a breach alert and contacts the people on the rule.

Table¶

The Exclusion zones table lists each zone with its number of breaches, grouped by type. Expand a zone to see the resources that breached it, and select Go to breach to see a breach on the map. Use Assign to Alert Rule in a zone’s menu to add a rule without leaving the table.

To test the alert set-up, select Simulate exclusion breach (the lightning button) above the table. See Checking who will be alerted.

Creating a Zone¶

Draw the zone with Create Zone in Map tools and choose Exclusion Zone in the pop-up. In Create New Exclusion Zone, enter a Name, choose a Type, and optionally a Parent Zone, Alert Rules and links. Select Create.

To upload exclusion zones from a file, select Upload, then Upload exclusion zones. The steps are the same as uploading workzones.

Screenshot

The Create New Exclusion Zone window

Breach Alerts¶

Alert rules decide when a zone raises alerts, who is contacted and which roles are allowed in. Set them up in Alert Management. The coloured dot beside each zone shows whether anyone will be contacted.

Breach History¶

To review past breaches, open Breach History in Analytics, or expand a zone in the Exclusion zones table.

To delete a zone together with its breach records, use Delete zone + breaches in the zone’s menu. This can’t be undone.

Alarm Buzzer¶

Some SMART tracking devices have a built-in alarm. When the wearer enters an exclusion zone, the device sounds a warning so they know to leave.

Alert zones¶

Alert zones decide who is contacted when someone raises an SOS. When a device’s SOS button is pressed inside an alert zone, SMART contacts the people on the alert rules assigned to that zone.

To create one, draw it with Create Zone in Map tools and choose Alert Zone in the pop-up. Enter a Name and Types, and optionally a Parent Zone and links, then select Draw if you want to change the shape. Assign rules to it in Alert Management.

The Alert Zones table lists each zone with its number of SOS alerts. Expand a zone to see each SOS, with the resource and time, and select Go to SOS to see it on the map. Simulate alert (the lightning button) previews who an SOS would reach.

Structures and floors¶

Structures are 3D models of buildings, sheds, tanks and other objects, placed on the map. People inside them show on the right floor, and you can cut the model away to see inside.

Select Structures in the navigation panel to see the Structures table and the Beacons table.

Adding a structure¶

You need edit permission to add or change structures.

  1. Select Add model.

  2. Choose a Model source:

    • Upload GLB: a GLB file exported in metres with Y up. File requirements and sample has a sample model and a Model preparation guide.

    • Generate with AI: describe a simple object, for example “A blue shed, 12 m wide, 8 m long and 6 m high”, select Generate draft, and refine it before saving. This works for sheds, site offices, containers, walls and tanks.

  3. Enter a Model name. Under Exclude parts, untick any parts of the model you don’t need.

  4. Check the floors SMART found under Confirm floors. For each one you can keep it, ignore it or edit it, including its name and walking surface. Select Add floor for any it missed.

  5. Choose whether to Place on map now (enter the latitude, longitude and elevation) or add it to the table as a model to place later.

  6. Select Upload model.

Screenshot

Adding a structure, with the model preview and floors

Placing and moving a structure¶

Drag a model from the Structures table onto the map to place it there. Each placement is a map instance, so one model can be placed several times.

While you are placing an instance, the Structure placement panel lets you Move, Rotate and change the Height, or type an exact Longitude, Latitude, Heading and Elevation. Turn on Snap to ground to sit it on the terrain. Select Save placement when it is right, and Lock placement to stop it being moved by accident.

Use Go to on an instance in the table to fly to it, and Adjust to move it again.

Floors and floor zones¶

In Map Layers, each structure has its own section. Show or hide the parts of each floor, and use the cutaway to see inside.

To create workzones for a floor, choose the floor under Structure floors and select Create floor workzone, or Assign zone to link an existing zone. Show floor zones shows them on the map.

Beacons¶

Bluetooth beacons let SMART locate people where GPS doesn’t reach, such as inside buildings. SMART adds a beacon to the Beacons table when a tracking device first detects it. Give it a surveyed position so SMART can use it.

  1. Select Structures in the navigation panel.

  2. In the Beacons table, select Place on the beacon’s row.

  3. Enter the surveyed Longitude (degrees), Latitude (degrees) and Surveyed mounting elevation (metres), then select Save beacon. The elevation is the beacon’s height in the project’s survey datum, not its height above the ground.

Use Move to correct a position, Disable to stop SMART using a beacon, and Delete to remove it. A deleted beacon isn’t added again when devices detect it.

To show beacons, their labels and their range rings on the map, use the Beacons section in Map layers.
