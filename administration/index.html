Administration¶

Administrators set up each project: its settings, its tracking devices and who can see and change what. You only see these options in the Main Menu if your account has administrator permissions.

Project Managers can update some key project settings, such as the geofence or shift times, through the Project Settings menu.

Work Day¶

Screenshot

Adjusting shift times for a project

You can adjust the start and end times of the shift. This allows SMART to provide better productivity estimates.

SMART currently only supports one configured shift for a project. If a schedule has been uploaded to a project, more precise details will be used in the analytics view.

Geofence¶

Screenshot

Editing the geofence for a project

Any devices outside of the project geofence will not upload data to SMART. For privacy reasons, this helps ensure that your staff are not tracked if they accidentally remove devices from the projecct site.

You can adjust the project geofence here at any time.

Device Management¶

Needs review

Carried over from the previous guide and not yet checked against the current app.

SMART has a completely self-service interface for managing which resource any given device is assigned to. To get the best results out of SMART, it is important to use all your devices and ensure that all resources on site are covered.

Device status¶

Status shows battery, a location pin and current zones. Hover the pin for coverage: green is inside, red outside and yellow pending triangulation. Position shows the last retained GPS fix; pending devices also show their latest Contact time.

Click the pin to show that position on the map, or click a zone to go to it. Outside or locationless contacts clear current zones while preserving the last retained position. Power-off and external-power warnings appear separately.

Assigned Resources¶

The Assigned tab shows all currently assigned resources for the project.

Each assignment has a role and a callsign. The callsign identifies the resource for that assignment, so a device can use a different callsign when it is reassigned.

If a device has been removed from a resource and is no longer in use, it should be unassigned. Click on the ⋮ button in the Action column, and then select ‘Unassign Device’.

Free Devices¶

The Free tab shows all SMART devices that are not currently in use. These can be assigned to a resource at any time.

Assigning a Device¶

Click on the ⋮ button in the Action column, and then select ‘Assign Device to Resource’.

Enter the callsign, choose ‘Select Role’, and select a role from the project hierarchy. Click ‘Assign Role’ to save the assignment.

Assign in Bulk¶

If you need to assign a large number of devices at once, it might be easier to use the bulk assignment function. Click on the ‘+ Assign in Bulk’ button, and then download the template spreadsheet. Fill in the resource details, save the file, and reupload the file.

Roles¶

A role represents a type of equipment or job function on site.

Roles can have a parent role. A role without a parent is a root role, and the Roles tab groups its descendants beneath it. For example, plant can contain Excavator, and personnel can contain Operator.

SMART uses the root role to recognise plant and personnel throughout the map, analytics, and schedule integration. Keep equipment beneath the plant root and people beneath the personnel root, including when using intermediate parent roles.

Creating a new Role¶

To add a new role to the project, click ‘Add Role’ in the top right of the table. Enter the role name, choose its parent role, and set its icon, costs, and fuel consumption as needed. Leave ‘Parent Role’ empty to create a root role.

Editing a Role¶

You can change the name, parent role, icon, costs, or fuel consumption associated with a role. Changing its parent also changes the hierarchy for any child roles. Roles with assignments or child roles cannot be deleted.

Importing from Schedule¶

If you have uploaded a schedule to SMART, you can import P6 resources as SMART roles to quickstart your project management. Review the parent role for each imported role before confirming the import.

Callsigns¶

A callsign identifies a resource during its device assignment. Reassigning a device preserves the callsign on each earlier assignment so historical reports retain the correct label.

User Management¶

Carried over from the previous guide and not yet checked against the current app.

SMART is best when working together! Once your project has been setup, you can invite friends and colleagues to join you in the platform.

Screenshot

User management table in SMART

In the Users tab, you can see everyone who currently has access to your project; and invite new users to the platform.

Adding New Users¶

To add someone new to your project, click the Add User button.

Screenshot

Creating a new user

Enter in the email address of whoever you want to invite to SMART. Every user is assigned to a permission group, which controls what they can and cannot do within the platform.

By default, SMART comes with three permission groups:

  • Administrator: full access to the platform. Administrators can configure key project settings, and grant access to new users.

  • SMART Coordinator: access to device management. This is a great role for supervisors on your project – they are able to manage device assignments but cannot add new users to the project.

  • SMART Read-Only Access: these users are able to browse through project data but cannot make any changes to the platform.

Once a user is added to the project, they will get an email inviting them to setup their account:

Screenshot

An example of the Welcome to SMART email

Each SMART project has a limited number of seats, depending on your current subscription plan. If you need to add more people to your project, contact us at sales@lwanalytics.com.

Permission Management¶

For most projects, the default permission groups should work fine, but if you want to create fine-grained access controls, you can manage permissions within the User Groups tab.
