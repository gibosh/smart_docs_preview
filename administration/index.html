AdministrationUpdated 24 Nov 2026

Administration¶

Administrators set up each project: its settings, its tracking devices and roles, and who can see and change what. These options are in the Main Menu (select the SMART logo in the navigation panel). You only see the ones your permissions allow.

Project Settings¶

Open the Main Menu and select Project Settings under Project.

General¶

Change the Project Name and the project’s Timezone. Times across SMART, including alert rule schedules, use this time zone unless a user chooses Local time in their display settings.

Schedule¶

Shows the Current Schedule version (the one SMART compares site activity with) and the Baseline Schedule version. Contact LWARE support to change either.

Under Schedule Versions you can see every schedule uploaded to the project, with its tasks, resources and zone assignments. To remove old versions, tick them and select Delete Selected. This deletes their P6 data and assignments for good. You can’t delete the current version.

Screenshot

The Schedule tab in Project Settings

Work Day¶

Set the Shift Start and Shift End times. SMART uses the shift to estimate productivity and to set where the timeline starts when you jump to a day. If a schedule has been uploaded, Analytics uses the schedule’s calendars instead where they are available.

Geofence¶

The geofence is the area where SMART tracks devices. Outside it, devices don’t record routine tracking data, so staff aren’t tracked if they take a device home.

The geofence is made up of one or more project zones:

  • Add polygon or Add rectangle to draw a zone. Tracking is recorded inside any zone marked Active. Inactive zones show in grey.

  • Cut out polygon or Cut out rectangle to remove an area, such as a neighbouring property, from every zone. Check the Cut-out preview, then select Apply cut-out to draft.

  • Select a zone in the list to edit its corners, Zoom to it or Delete it. Fit project zooms to the whole geofence.

Save your changes when you are done. They apply to new data only; data already recorded stays as it is. SOS alerts are always recorded, including outside the geofence and inside cut-outs.

Editing the project geofence

Device Management¶

Open the Main Menu and select Device Management under Project. Every tracking device is assigned to a resource with a role and a callsign. Keep the assignments up to date as devices move between people and machines, so SMART reports against the right resource.

Device status¶

The status column shows each device’s battery, position and current zones.

  • Hover over the location pin to see whether the device is inside the geofence (green), outside it (red) or waiting for a position (yellow), and when it last reported.

  • Select the pin to show the device’s last position on the map, or select a zone to go to it.

  • Powered off and External power disconnected warnings show when they apply.

Assigned resources¶

The Assigned tab lists every device in use, grouped by root role, with its role and callsign.

  • Unassign Device: in the row’s Actions menu, when a device is taken off a resource and not reused.

  • View Device History: see each callsign and role the device has had, with dates.

  • Reassign Selected: tick devices and give them a new role or callsign in Bulk Reassignment. You can backdate the change to when it really happened. Backdating replaces any assignments after that date.

  • Unassign Selected, Export CSV and Export as upload work on the ticked devices or the whole list.

A callsign belongs to an assignment, so a device can have a different callsign each time it is reassigned. Earlier assignments keep their callsigns, and past reports show the right names.

Free devices¶

The Free tab lists the project’s devices that aren’t in use.

To assign one, select Assign Device to Resource in its Actions menu. Enter a Callsign, choose Select Role, pick the role and select Assign Role. If the role doesn’t match the kind of device (for example a personnel role on a plant tracker), SMART warns you.

To assign many devices at once, select Assign in Bulk:

  1. Download the template spreadsheet.

  2. Fill in each Device ID, Role and Callsign. Use the role ID if two roles share a name. Save the file as CSV.

  3. Upload the file, match its columns to the device fields, and check the preview. Rows with an unknown device ID are removed.

  4. Select Assign.

Roles¶

A role is a type of equipment or job, such as “Excavator” or “Traffic Controller”. Roles sit in a tree: a role without a parent is a root role, and the Roles tab groups each root’s roles beneath it.

SMART uses the root roles to tell plant from personnel on the map, in Analytics and in the schedule. Keep equipment under the plant root and people under the personnel root, even when you add roles in between.

  • Add Role: enter the Role Name, choose a Parent Role (leave it empty for a root role), and Choose Icon. For plant, you can add the Model, Operating Weight (Tonnes), Cost per hour and Fuel Consumption (L/hr) when idle and working. Analytics uses the costs and fuel figures.

  • Edit Role: change any of these. Moving a role to a new parent moves its child roles too.

  • Delete Role: only for roles with no assignments and no child roles.

  • Import from Schedule: if you have uploaded a schedule, select the schedule’s resources to create matching roles, check the parent of each, and select Confirm.

Zone types are managed in the Zone Types tab. See Workzone Types.

User Management¶

Open the Main Menu and select Users under Users to see everyone with access to the project.

Screenshot

The Users table

Adding New Users¶

  1. Select Add User.

  2. Enter their Email and Name, and choose their Permission groups.

  3. Select Create. SMART sends them a welcome email with a link to set up their account.

To change someone’s details or groups, select Edit user. To take away their access, select them and select Remove User.

Each project has a set number of seats, depending on its subscription. To add more, contact LWARE.

Permission groups¶

Every user belongs to a permission group. New projects have three:

Group

Can

Administrator

Do everything, including changing project settings and adding users

SMART Coordinator

Manage devices and assignments, but not users

SMART Read-Only Access

View project data without changing anything

To set up your own groups, open User Groups under Users in the Main Menu and select New group. Give the group a name and choose its Access scope:

  • Project-wide: pick the actions members can take across the whole project: View SMART, Manage SMART, View schedules, Upload schedules and Manage users.

  • Selected role branches: members get read-only access to the resources and work in the role branches you choose, including roles added to those branches later. Turn on View all project safety alerts if they also need to see every breach and SOS.

If your organisation signs in to SMART with company accounts, choose the Default group for new enterprise sign-ins: the access people get the first time they sign in to the project.

Creating a permission group

Recommendations and videos¶

Open the Main Menu and select Recommendations under Account to see what is left to set up on the project, such as assigning devices, uploading a schedule, creating work areas, adding costs to roles and setting up breach alerts. Select Go beside a recommendation to open the right screen. When there is nothing left, SMART says the project is fully set up.

Videos opens the Training Videos list. Select Play Video to watch one.
